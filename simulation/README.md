# Simulation

Le moteur de simulation multi-agents et l'optimisation des tournées se trouvent dans le backend :

- `backend/app/full-stack-fastapi-template/backend/app/simulation/` : agents, modèle et `parametres.yaml`
- `backend/app/full-stack-fastapi-template/backend/app/optimization/` : points de regroupement et tournées

Voir `README.md` dans le dossier `simulation` du backend. Côté admin : pages Plan de gestion, Paramètres de simulation et Comparaison de scénarios.
