# Rapports de donnees

Ce dossier contient des rapports reproductibles produits a partir des sources du depot. Les rapports de demonstration doivent rester clairement marques comme synthetiques et ne pas etre confondus avec des indicateurs de terrain.

`rapport_demo_faso_neere.json` resume le jeu synthétique de `../reference/jeu_demo_faso_neere.json`. Il n'est pas produit a partir de PostgreSQL, de signalements reels ou d'une extraction OSM.

Pour tout futur rapport operationnel, documenter au minimum la source, la periode, la date de production, les filtres appliques, les limites de couverture et les versions des donnees d'entree.
